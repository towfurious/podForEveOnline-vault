# EVE Online KMP Project Wiki

An Obsidian vault serving as this project's persistent, compounding knowledge base.

- Open this folder as a vault in Obsidian.
- The wiki is maintained by an LLM agent following `[[CLAUDE]]`.
- Raw sources go into `sources/raw/`. The LLM ingests them and integrates facts into `wiki/`.
- Browse via `[[index]]` or Obsidian's graph view.
- `[[log]]` is the chronological record of all operations.

Start here: `[[CLAUDE]]` (schema) · `[[index]]` (catalog) · `[[log]]` (timeline).

This vault is planned to move into its own git repository. For now it is gitignored by the parent app repo.
